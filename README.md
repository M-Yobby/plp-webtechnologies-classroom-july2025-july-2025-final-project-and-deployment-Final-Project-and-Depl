
# ABC Law Firm Website

A professional, responsive, and multi-page website built for a fictional law firm.  
This project demonstrates HTML5, CSS3, and JavaScript skills, including responsive layouts, navigation menus, card-based services, and a gallery.  

Deployed on: (https://m-yobby.github.io/plp-webtechnologies-classroom-july2025-july-2025-final-project-and-deployment-Final-Project-and-Depl/)

---

## Features

- **Multi-page structure**:
  - Home
  - About
  - Services
  - Gallery
  - Contact

- **Responsive design** that adapts to desktop, tablet, and mobile devices.
- **Sticky navigation bar** with a toggle menu for smaller screens.
- **Hero section** with a background image and call-to-action.
- **Services section** displayed in card layout for readability.
- **Gallery section** in a neat grid with hover effects.
- **Contact form** with styled inputs and button.
- Consistent **header and footer** across all pages.
- Organized folder structure for maintainability.

## Technologies Used

- **HTML5** – semantic structure and accessibility.
- **CSS3** – styling, responsive layouts, grids, flexbox, hover effects.
- **JavaScript (Vanilla)** – mobile menu toggle interactivity.
- **Responsive Web Design (RWD)** – media queries for multiple screen sizes.
